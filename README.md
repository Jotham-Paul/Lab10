# Web Programming Lab 10: PHP Sessions, Cookies & Form Processing

This repository contains practical implementations for Web Programming Lab 10:

## 📂 Structure

- **`1/`**: PHP Session Management (tracking active session time and user details across `index.php`, `hello.php`, and `logout.php`).
- **`2/`**: PHP Cookie Handling (setting and retrieving cookie expiration and persistence).
- **`3/`**: PHP Form Verification & Access Control (validating age and user authorization via `index.html` and `verify.php`).
